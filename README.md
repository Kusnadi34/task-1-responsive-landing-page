# Task 1: Responsive Landing Page - NovaBrew

A modern, fully responsive landing page for a fictional smart coffee maker product called **NovaBrew**. This project was built as part of the Frontend Developer Internship program at Auspify Technologies.

## 🚀 Live Demo
*(Tambahkan link Netlify/Vercel Anda di sini nanti, contoh: [Live Demo](https://novabrew-landing.netlify.app))* 

## ✨ Features

- **Mobile-First Design:** Optimized for mobile devices first, scaling beautifully to tablets and desktops using Media Queries.
- **Interactive Navigation:** A sticky navigation bar with a functional hamburger menu for mobile users.
- **Smooth Scrolling:** Seamless scrolling navigation between sections.
- **Dynamic Modals:** Interactive popups for selecting pricing plans and completing a simulated pre-order form.
- **Scroll Reveal Animations:** Elements fade and slide in as the user scrolls down the page (using Intersection Observer).
- **Modern UI/UX:** Clean layout utilizing CSS Flexbox and Grid, with a warm coffee-inspired color palette.

## 🛠️ Tech Stack

- **HTML5:** Semantic and accessible markup.
- **CSS3:** Custom properties (CSS Variables), Flexbox, CSS Grid, and media queries for responsiveness.
- **Vanilla JavaScript:** DOM manipulation, event handling, and Intersection Observer for animations. No external libraries used.
